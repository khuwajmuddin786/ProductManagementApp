# Product Management System

## Project Overview

The Product Management System is a full-stack web application developed using Angular 20, ASP.NET Core Web API, and SQL Server. It allows users to manage product records efficiently through a responsive and user-friendly interface.

This project was created for learning and practicing full-stack development concepts including frontend development, backend APIs, and database integration.
